# Site — prévia de desenvolvimento

Abra `index.html` a partir da raiz ou execute `python3 -m http.server 8000 --bind 0.0.0.0`. Site estático, sem dependências externas. As fontes e imagens do protótipo são locais.

`catalogo.js` concentra as categorias e produtos aprovados. A lista começa vazia porque o pacote não contém dados comerciais validados; a vitrine mostra apenas referências provisórias. Para cadastrar, use os formatos indicados no arquivo, com IDs únicos, caminhos relativos à raiz e até 15 produtos. `categoriaId` deve corresponder ao `id` de uma categoria. Os filtros aparecem automaticamente quando houver categorias. Imagens de referência não são fotos dos produtos.

O Instagram informado pelo cliente está ligado no contato. O número de WhatsApp é pendente: não usar o número de exemplo do protótipo. Após receber o número, implementar os links de atendimento e de produto com mensagens codificadas. Faltam ainda lista e classificação de produtos, preços, fotos autorizadas, destaques e textos institucionais. A versão do logotipo com o descritivo “Cartomancia” também precisa ser confirmada. Não publicar a prévia como versão definitiva.
